# Модель оценки (решение по Q-1)

Статус: принято владельцем (D-014). Открытые места отмечены `[Q-n]`, не гадать, спрашивать.

## Принцип
Два слоя: **объективные измерения** (тесты) + **экспертная оценка тренеров** по единой шкале. Результат сопоставим между наборами и тренерами.

## Шкала критерия: 1–5
| Балл | Значение |
|---|---|
| 1 | Не соответствует возрастному уровню |
| 2 | Ниже ожидаемого |
| 3 | Соответствует возрасту |
| 4 | Выше ожидаемого |
| 5 | Существенно выше возрастного уровня |

Не показывать детям «место в списке» и общий публичный рейтинг. Родителю: профиль навыков и процентиль по возрастной группе `[Q-5: уточнить, нужен ли процентиль]`.

## Возрастные профили (критерии и веса)
**U7–U9** (по 25%): комфорт с мячом · координация и ловкость · активность и желание играть · обучаемость.

**U10–U11:** контроль мяча 20% · передачи 20% · скорость и ловкость 15% · игровое мышление 20% · обучаемость 10% · отношение к игре 15%.

**U12–U14:** контроль мяча 15% · передачи и приём 15% · скорость 10% · игровое мышление 20% · тактика 15% · обучаемость 10% · характер и коммуникация 15%.

Сумма весов в каждом профиле = 100% (проверять тестом).

## Объективные тесты
| Тест | Как считается | В балл 1–5 |
|---|---|---|
| Спринт 20 м | лучшая из двух попыток | по возрастному нормативу |
| Челнок 5–10–5 | лучшая из двух попыток | по нормативу |
| Ведение с мячом | время дистанции | по нормативу |
| Точность передач | успешные из 10 | по нормативу |
| Удары по воротам | попадания из 10 | по нормативу |

Для U7–U9 тайминговые спринты необязательны. Нормативы (границы 1–5 по возрасту) нужно взять из источника `[Q-6: источник нормативов; не придумывать цифры]`. Используется спринт 20 м (референс игнорируется, D-018).

## Формула
```
Итог = Σ (оценка_i × вес_i)        // 1.00 … 5.00
```
- Несколько тренеров: берётся **медиана** их оценок по критерию, не среднее.
- Пример U10–U11: 4·0.20 + 3·0.20 + 4·0.15 + 3·0.20 + 4·0.10 + 5·0.15 = **3.80**.

## Статусы решения (по умолчанию)
| Статус | Правило |
|---|---|
| Зачислен | Итог ≥ 4.00 и нет критерия с оценкой 1 |
| Резерв | 3.50–3.99 |
| Повторный просмотр | 3.00–3.49 или сильное расхождение тренеров |
| Не зачислен | < 3.00 |

В MVP пороги предзаданы, чтобы наборы были сопоставимы. Академия может менять пороги позже.

## Что это значит для реализации
- Модуль `src/server/scoring/`: чистые функции, TDD (задача T-040). Профили и пороги — данные (конфиг), не код в компонентах.
- «Сильное расхождение тренеров» нужно определить числом `[Q-7]` (например, разница оценок ≥ 2).
- Роль ИИ: в этой модели оценки ставят тренеры и тесты. ИИ-анализ видео предлагаем как **подсказку** (черновик оценки «контроль мяча», «передачи», «игровое мышление»), которую тренер подтверждает или меняет (D-019).
- Отображение итога: 1.00–5.00, без пересчёта в 0–100 (D-018). Референс с «87/100» игнорируется.
