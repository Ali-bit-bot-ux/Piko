# Журнал решений

Формат: ID, статус (`принято` / `предложено`), решение, почему. Новые решения добавлять вниз. Агент не меняет `принято` без согласия людей.

| ID | Статус | Решение | Почему |
|---|---|---|---|
| D-001 | принято | Next.js (App Router) + TypeScript, один репозиторий для фронта и бэка | Быстрый MVP, меньше связности |
| D-002 | принято | Модель анализа и хранилище только за интерфейсами `AnalysisProvider`, `Storage` | Напарник подключит Google Cloud без переписывания |
| D-003 | принято | Первый провайдер анализа: Claude | Решение команды |
| D-004 | принято | Видео в модель передаём кадрами, а не целиком | Контроль цены и качества |
| D-005 | принято | Язык UI: русский, архитектура готова к казахскому | Рынок Казахстана |
| D-006 | принято | Mobile-first дизайн по референсу `docs/reference/landing.webp` | Тренеры и родители с телефона |
| D-007 | принято | Tailwind CSS + токены в CSS-переменных | Быстрая адаптивная вёрстка |
| D-008 | принято | Postgres + Prisma | Реляционная модель, подходит Cloud SQL |
| D-009 | принято | Auth.js, роли `admin`, `coach`, `parent` | Стандартное решение для Next.js |
| D-010 | принято | zod для схем (отчёт модели, формы, API) | Одна схема для типов и валидации |
| D-011 | принято | Тесты: Vitest (логика), Playwright (сценарии) | Скоринг должен быть покрыт тестами |
| D-012 | принято | Хуки плагина everything-claude-code не используем | Решение владельца |
| D-013 | принято | Реальные логотипы организаций и «50+ академий» с референса не публикуем без подтверждения | Референс — макет |
| D-014 | принято | Модель оценки: шкала 1–5, возрастные профили и веса, медиана тренеров, нормализация тестов по возрасту, 4 статуса решения (`docs/scoring.md`) | Решение Q-1, сопоставимость между наборами |
| D-015 | принято | Источник истины: серверный append-only журнал событий, исправления новыми событиями (`docs/event-log.md`) | Решение Q-2, аудит и спорные случаи |
| D-016 | предложено | Тарифная сетка Пилот/Секция/Академия/Сеть/Федерация (`docs/pricing.md`). Цены предварительные, точка безубыточности пересчитана и расходится с исходной | Решение Q-3 частично, нужен пересчёт (Q-10) |
| D-017 | принято | Базовый отчёт родителю бесплатный; платные опции только после решения о зачислении и не влияют на него | Доверие родителей и тренеров |
| D-018 | принято | Референс `docs/reference/landing.webp` — фейковый набросок. Берём только дизайн, расположение кнопок и информации. Тексты, цифры (87/100), критерии, тесты (спринт 30 м), логотипы с него не берём. Оценка и статусы: по `docs/scoring.md` (итог 1.00–5.00, статусы Зачислен/Резерв/Повторный просмотр/Не зачислен, спринт 20 м) | Решение владельца (Q-5, частично Q-6) |
| D-019 | принято | Роль ИИ: подсказка тренеру (черновик оценки по видео), оценку подтверждает или меняет тренер. Итоговая оценка не ставится ИИ автоматически | Решение владельца (Q-8) |
| D-020 | принято | Видеозаписи удаляются после завершения набора и отправки отчётов родителям. В журнале событий только псевдонимные ID, имя и контакты хранятся отдельно и удаляются по запросу | Решение владельца (Q-9), минимизация данных детей |
| D-021 | принято | Цены на сайте пока заглушки (`docs/pricing.md` остаётся предложением, Q-10 отложен) | Решение владельца (Q-10) |
