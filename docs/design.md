# Дизайн Piko

Референс: `docs/reference/landing.webp` — фейковый набросок (D-018). Берём только дизайн, расположение кнопок и информации. Тексты, цифры (87/100), критерии, логотипы не берём. Значения ниже получены на глаз по картинке, это ориентир. При вёрстке сверять с референсом и уточнить.

## Принципы
1. **Mobile-first.** Тренеры и родители смотрят с телефона. Сначала 375 px, потом планшет и десктоп.
2. **Дружелюбно.** Ребёнка и родителя не пугаем. Акцент на росте и сильных сторонах. Слабые стороны формулируем как «над чем поработать».
3. **Интуитивно.** Один главный путь на экране, одна главная кнопка. Понятные подписи, без жаргона.
4. **Быстро в поле.** Экран испытания: крупные кнопки и цифры, управление одной рукой.
5. **Прозрачно.** Всегда видно, по каким критериям считалась оценка.
6. **Доступно.** Контраст, видимый фокус, подписи у иконок, клавиатура.

## Визуальный язык (из референса)
- Цвета: фирменный зелёный (насыщенный для кнопок, лайм для акцентов и градиента), белый, светло-серый, очень тёмный (почти чёрный) для карточки таймера, зелёная галочка для «пройдено».
- Токены задавать как CSS-переменные в `src/styles/tokens.css`: `--color-primary`, `--color-accent`, `--color-surface`, `--color-text`, `--color-dark`, `--radius-card`, `--shadow-card`.
- Форма: скруглённые карточки (16–24 px), мягкие тени, «плавающие» карточки поверх фото.
- Шрифт: геометрический гротеск (Inter или подобный), заголовки жирные, кириллица обязательна.
- Иконки: линейные, единый набор (например Lucide).
- Ключевые компоненты: `ScoreRing` (кольцо с итогом по шкале 1–5 из scoring.md), `CriteriaList` (галочки), `StepCard`, `Badge` («Рекомендован»), `TimerCard` (тёмная карточка с таймером), `ReportCard`, `Button` (primary, secondary, ghost).

## Блоки лендинга
1. Шапка: логотип, меню (О платформе, Для академий, Для родителей, Тарифы), «Войти», «Начать бесплатно».
2. Hero: заголовок, подзаголовок, две кнопки («Начать набор», «Узнать больше»), фото + плавающие карточки (пример результата, критерии, отчёт; цифры только заглушки).
3. Полоса доверия (заглушки, без реальных логотипов).
4. Четыре преимущества: честный отбор, экономия времени, больше доверия, развитие игроков.
5. «Простой процесс отбора в 5 шагов».
6. Тарифы, подвал.

## Адаптивность
- Mobile: меню в бургер, hero в одну колонку, плавающие карточки под фото, шаги в вертикальный список.
- Tablet/desktop: как на референсе.
- Проверка: 375, 768, 1280 px.
